## Model download

The provided analysis script will download the default model and labels upon first run.

You can download models manually from [Zenodo](https://zenodo.org/records/20703646).

We provide the following models:

- TorchScript model in FP32 format (`BirdNET+_V3.0-preview3.1_Global_11K_FP32.pt`)
- ONNX model in FP16 pruned format (`BirdNET+_V3.0-preview3.1_Global_11K_FP16_pruned.onnx`)

Please make sure to review the [license](../LICENSE) and [terms of use](../TERMS_OF_USE.md) before downloading the models.
